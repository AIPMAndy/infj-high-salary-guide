## 编辑判断 / 实战建议 / 示例，必须分开

- **研究信息**：MBTI 不应作为招聘筛选依据；O*NET 可用于职业兴趣探索；谈薪应结合证据和替代方案。
- **编辑性建议**：本文的六步路径、岗位清单、30 天计划、PAR 案例卡、会议脚本是作者整理的实践框架，尚无随机对照研究能证明整套框架的特定涨薪效果。
- **演示案例**：任何文中标注「演示」「例如」的数值或话术均不代表作者客户案例，除非另有经允许披露的证据。
- **薪酬数据**：不提供未经核验的「INFJ 平均工资」「AI 岗平均薪资」或「晋升概率」数字；用户必须根据城市、行业、级别、日期和薪资口径自行核查。

## 适用区域

主体示例以中国城市职场、科技互联网 / AI / ToB 相关岗位为主。劳动用工制度、合同、税制、社保、竞业限制与晋升规则以实际地区和公司为准。部分国际链接用于解释方法，不意味着其薪酬和法律制度适用于中国。

## 后续维护建议

每季度审查外链、市场相关表述和站点功能。新加数据时注明来源、发布日期、采样维度、样本量与适用范围，避免过期信息被读者误认为实时工资标准。
