# 01｜INFJ 怎么找更高薪的职业方向

## 别先问「INFJ 适合什么」

同一种 MBTI 类型，教育、行业经验、技能和就业环境可能差异巨大。要找的是：**市场有人付费 + 你能持续创造价值 + 你有真实证据** 的交集。

## 选岗四步法

1. **拆业务责任。** 从目标岗位 JD 提炼它真正要负责的结果：收入、留存、成本、客户满意、决策质量、组织效率、产品采用等。
2. **对照证据。** 你是否做过类似问题？参与、主导、决策和最终负责分别有什么可查依据？
3. **算转型成本。** 硬技能缺口、是否要求行业资质、可接受收入下降时间、家庭与城市约束都要考虑。
4. **做低成本试验。** 一次内部跨团队项目、一个真实作品集、一段客户访谈，都比空想换行更有价值。

## 岗位比较打分卡（自定义工具，不是心理测评）

每项 0–2 分，分别打在两个岗位上。0 = 不满足，1 = 部分满足，2 = 有证据满足。

| 维度 | 岗位 A | 岗位 B |
| --- | --- | --- |
| 核心任务经验可迁移 | | |
| 关键硬技能具备 | | |
| 能展示真实成果 | | |
| 近期市场有可验证需求 | | |
| 个人生活和风险约束可接受 | | |

**不要机械按总分定岗位。** 某个强制资格证或经验门槛可能是一票否决，薪资样本太少也应暂不下结论。

## 两种常见误判

**「我善于共情，所以一定适合 HR。」** HRBP 的高职级职责往往同时包括组织诊断、人才机制与业务经营约束。共情只能帮助建立信任，无法替代业务能力。

**「我喜欢 AI，所以转 AI 产品就能拿高薪。」** 岗位更关心需求选择、产品交付与业务效果。先做出能证明价值的小项目，再考虑投入更高成本。

## 交付物

两份岗位 JD 矩阵；一份能力缺口清单；一个两周内可执行的证据项目。职业兴趣自查也可以用 [O*NET Interest Profiler](https://www.onetcenter.org/IP.html)，它是职业兴趣探索工具，**不替代对市场和能力的判断**。
